# Sistem Pakar

## Deskripsi
Proyek ini dibuat menggunakan bahasa pemrograman Python untuk mempelajari konsep sistem pakar dan sistem multi-agent.

## File Program
- `main.py`: File utama untuk menjalankan program.
- `manager.py`: Berisi fungsi dan logika pengelolaan program.

## Teknologi
- Python

## Cara Menjalankan
1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

```bash
python main.py
```
